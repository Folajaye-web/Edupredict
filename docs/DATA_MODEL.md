# EduPredict Nigeria — Data Model

Core entities: School, AcademicSession, Student, Subject, AssessmentPolicy, Result, Attendance, Engagement, Prediction.

The model separates identity, academic period, subject results and attendance so a student can be followed across terms and sessions.

The application is designed to support the current Nigerian curriculum structure while keeping school assessment policies configurable. NERDC publishes revised Basic Education and Senior Secondary curricula, and the Federal Ministry of Education has announced a revised national curriculum structure.
